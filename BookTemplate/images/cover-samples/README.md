샘플은 참고용이므로 PDF에 그대로 쓰지 않는다. 실제 표지는 아래 세 경로 중 하나로 만든다.

## 표지를 만드는 세 경로

1. **템플릿 표지 (권장, 09 계열)**: `books.py`에 `"cover": {"mode": "green-gold", ...}`만 넣으면 빌드 때 09번 구도로 표지가 조판된다. 간지·표·저자 소개도 녹색·금색 `green` 테마로 맞춰진다. 키 설명은 `책만들기_종합_지침서.md` §5 참조.
2. **Higgsfield 원화 + 템플릿 타이포**: 샘플의 구도·팔레트를 프롬프트에 서술하거나 샘플 파일을 참조 이미지로 올려 `generate_image` → `images/<책>-cover.png`, `"mode": "image", "overlay_text": True`.
3. **Canva 마감**: Canva에서 같은 템플릿을 열어 제목·저자를 바꾸고 PNG로 내보내 `images/<책>-cover.png`, `"mode": "image", "overlay_text": False`. 판형 비율(신국판 152:225, B5 188:257)에 맞춰 크기를 조정한 뒤 내보낸다(샘플 원본은 0.63:1이라 그대로 쓰면 위아래가 잘린다).

## 새 샘플 세트 추가 규칙

- `cover-samples/<출처>-<세트이름>/NN_<제목>_<특징>.jpg` 형식으로 넣는다.
- 이 README 표에 한 줄씩 구도·팔레트·어울리는 책을 적는다.
- 샘플 속 저자명·출판사명은 템플릿 더미이므로 실제 표지에 옮기지 않는다.
